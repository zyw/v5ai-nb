# 对话门户

`v5ai-ui-chat` 是独立的终端用户界面。用户使用管理员签发的 Agent API Key 登录，选择可用的已发布 Agent，开始对话并管理自己的会话。

![对话门户主页](/images/chat-home.png)

## 登录与可见范围

门户先请求 `GET /api/v1/agents/auth/bootstrap`，取得当前 Key 可访问的 Agent、展示信息以及是否支持图片和引用展示。会话的归属主体是 **API Key**：同一把 Key 的会话可以互相看到，不同 Key 隔离；管理端调试产生的会话不会出现在门户列表中。

API Key 明文只在创建时展示。门户把 Key 保存在当前浏览器，请勿在公共设备上使用。

## 一次对话

选择 Agent 后，可从推荐问题开始，也可以直接输入文字。门户通过 SSE 接收增量回答、工具事件与完成事件；回答可包含思考折叠区、知识库引用及用量信息。

如果 Agent 绑定的对话模型声明 `image` 能力，门户可上传 PNG、JPEG 或 WebP 图片后提问。每张默认最多 5 MB，每条消息默认最多 3 张；附件读取仍需本 Key 的归属校验。

## 会话管理

- 会话列表、改名与归档存放在服务端；归档后不能继续对话。
- 用户可停止正在生成的回答；已生成的部分内容仍会保存。
- “重新生成”会让旧助手消息作废，历史读取只展示新版本。
- 标题先取首条问题，再可由 Agent 的次要模型异步改写。用户手动改名后不会再被自动覆盖。

## 生效时机

门户读取已发布快照与页面初始化时的 bootstrap。修改 Agent 绑定模型、次要模型、引用展示等字段后，管理员需**重新发布**；终端用户需**刷新或重新登录**。仅为当前已绑定模型添加 `image` 能力时，不需要重新发布，但门户同样要刷新。

接口契约与错误码见仓库 `docs/api/phase6.md`；独立部署见[本地开发部署](/zh/deploy/local)。
